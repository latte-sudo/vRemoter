# vRemoter 首次引导与设置交互原型

`vremoter-onboarding-settings.html` 为已确认的第 6 版独立 HTML 原型，按原文件逐字节保存。直接用桌面浏览器打开即可；图片、样式和脚本均内嵌，无需构建、安装依赖或联网。

## 当前范围

- 首次引导、应用设置、设计令牌三个入口；七步引导含六段进度连接线，第六步按键配置仅为非交互展示位
- 简化的语音试用：真实遥控器图片标出黑色语音键，提示随按住／切换模式变化，结束后需明确确认示例文字
- 遥控器概览合并图片、本地显示别名、连接状态和操作，其下保留按键配置展示位
- 语音和音频独立成页；设置页依次包含主题切换、启动与程序坞、配置备份、恢复与重来
- 全局模拟说话状态在三个入口间保持一致；设计令牌直接读取界面使用的 CSS 变量
- 导入与重置需要明确确认，支持取消和操作前导出备份；不提供最近一次修改的撤销功能

## 使用边界

设备连接、权限、应用启动、语音及设置操作均为模拟，不修改原生 macOS 应用、硬件、蓝牙名称或系统设置。此次提交不包含原生实现或重构。

演示偏好和进度仅保存在浏览器的 localStorage 中。导入／导出的 JSON 是原型专用格式，与原生应用的配置档案不互通。HTML 本身不包含用户浏览器保存的状态。

此目录用于设计评审与交互参考；保存到仓库不代表部署官网或发布应用。

## 离线检查

需要支持 Blob 的 Node.js 18 或更新版本，无第三方依赖。在仓库根目录执行：

```sh
node --check docs/prototypes/test-vremoter-onboarding-settings.cjs
node docs/prototypes/test-vremoter-onboarding-settings.cjs
```

测试脚本会在 Node VM 中编译并运行 HTML 内的 JavaScript，覆盖 62 项交互与状态回归。它使用模拟 DOM，不能替代真实浏览器的视觉、布局或无障碍验证；本次归档未执行浏览器视觉检查。
