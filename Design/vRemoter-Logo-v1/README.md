# vRemoter Figma Logo

这是保留的上游品牌设计源和本地 Figma 插件包，用来在当前打开的设计文件中生成 `vRemoter · Brand Logo System`。当前应用打包使用 `vRemoter-app-icon-v9.png`；本轮清理没有改动标志、图标或品牌身份。旧的 X6 / 混音器封版 UI 已删除，不再作为当前界面设计依据。

## 使用方法

1. 打开 Figma 桌面版，打开一个可编辑的设计文件；不需要已删除的旧封版 UI 文件。
2. 打开菜单：`Plugins → Development → Import new plugin from manifest…`
3. 选择本文件夹里的 `manifest.json`。
4. 再次打开：`Plugins → Development → vRemoter Logo`。
5. 插件会在已有 `vRemoter · Studio Mixer States` 右侧生成 logo 画板；如果当前页面没有这个画板，则生成到最右侧空白处。

插件会替换同名的 `vRemoter · Brand Logo System`。运行前确认当前文件中该画板可以被替换；其余画板不受影响。

## 标志逻辑

- 图形整体先读作立式麦克风，同时保留清晰的字母 `V` 骨架。
- `V` 同时代表 `vRemoter`、`Vibe Coding` 和 `Vincent`。
- V 的两条笔画分别抽象为一支斜放的智能电视遥控器；每支遥控器使用顶部方向圆环与下方纵向 Pill 键作为核心识别特征。
- 绿色只作为信号波纹和状态提示；遥控器机身使用中性灰，避免把状态色误读成整套品牌主色。
- 上方的无线波纹组成麦克风网罩，最靠近发射点的一圈最亮，向上逐层减弱。
- 两支遥控器保持较大的 V 形开口，并在底部自然汇合，不添加独立圆点或装饰尾巴。
- V 角度锁定为 85°：两条遥控器中心线固定为 `M73.35 128 → M110 168` 与 `M146.65 128 → M110 168`，后续版本不得调整这个角度。
- 五层波纹的弦长固定为“短、次短、最长、次短、短”，上下对称；曲率规则保持一致。
- 波纹基线固定等距 16 px；完整五层的基线高度为 `124/108/92/76/60`，缩小版本只按层数删减，不改变间距规则。
- 完整版本使用五层波纹；64 px 使用三层波纹并保留简化按键，32 px 和 16 px 才移除按键细节。
- 横向组合标由 V 图形直接充当首字母，右侧只写 `Remoter`，整体读作 `vRemoter`。
- 彩色、浅色、单色以及 16/32/64/128 px 版本保持同一轮廓。
